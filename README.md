# 💼 Personal Portfolio Website

A responsive personal portfolio website created to showcase my education, technical skills, projects and contact information.

## 🚀 Features

- Responsive design
- Home section
- About section
- Skills section
- Projects section
- Education section
- Contact section
- Mobile navigation menu
- Simple and clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

No server or database is required.

## 🌐 GitHub Pages Deployment

The project can be deployed using GitHub Pages:

1. Upload the files to a GitHub repository.
2. Open **Settings → Pages**.
3. Select the `main` branch and the root folder.
4. Save the settings.
5. GitHub will provide the published website URL.

## ✏️ Customization

Before publishing, replace:

- `Your Name`
- `your-email@example.com`
- GitHub profile link
- LinkedIn profile link
- Project GitHub links
- Any project descriptions that need updating

You can also add your profile photo inside the `assets` folder.

## 📌 Purpose

This portfolio is designed to present academic projects, technical skills and career-related information in one place.
